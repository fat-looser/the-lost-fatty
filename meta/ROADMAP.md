## 每章工作流

```
命题 → 证据卡 → 提纲 → 初稿 → 自审 → 发布 → 社区纠错 → 修订
```

1. **命题**：一句话写清本章核心问题。写不出来说明还没想清楚，不开工
2. **证据卡**：先在 `evidence/claims/` 建卡，再写正文。**没有卡的数字不进正文**
3. **提纲**：按 [OUTLINE.md](OUTLINE.md) 的骨架细化到小节
4. **初稿**：按 [STYLE.md](STYLE.md) 的统一结构写
5. **自审**：三张清单——证据（每个数字有源？）、伦理（有羞辱/医疗越界/隐私？）、语气（第一人称是否贯穿？结论是否锋利但不越界？）
6. **发布**：`status: published`，更新本文件与 CHANGELOG
7. **社区纠错**：Issue 进来的事实错误 48 小时内响应
8. **修订**：公开修订，重大观点推翻要在 CHANGELOG 里写明理由

## 风险清单

| 风险 | 应对 |
|---|---|
| **医疗越界**（最高优先） | EDITORIAL 医疗红线硬执行；不给剂量；每章免责；涉及疾病/药物附就医指引 |
| 诱发进食障碍模仿 | 不写方法、不渲染极端数字；只写识别信号与求助路径 |
| 诽谤 / 名誉权 | 点名机构只用公开可查证材料；出版前法务通读；不做主观定性 |
| 隐私泄露 | 知情同意 + 脱敏 + `raw/` 不入库；**本地私人语料不进公开仓库** |
| 时效性（34、35 章半衰期最短） | 「快照 + 机制」双层写法：数据标注截至日期，机制分析单独成段可跨周期成立 |
| 沦为控诉文学 / 廉价共情 | 每章「反方与局限」+ 军规第 7 条 + 辩证转折（OUTLINE 0.6） |
| 行业数据不透明、报告利益相关 | 交叉验证 + 注明发布方立场 + 证据卡记录利益相关 |
| 访谈征集冷启动 | 先用自身网络 + 社区发帖；P2 启动前完成 20 人 |
| 体量失控 | 每章 8000 字硬上限；卷二卷三各可压缩至 4 章的预案 |
| 数据核不实导致论点塌方 | 没有卡的数字不进正文；关键论断至少两个独立来源 |
| **AI 检索内容未经人工签字**（本轮新增，最高优先） | 46/58 卡仍「待核实」。**这不是瑕疵，是论点的落实**——但正文不得引用未签字的卡 |
