# 术语与黑话词典

> 附录 A 的工作版。中英对照 + 圈子黑话。术语首次出现时在正文给定义，之后统一用本表用词。
> 释义力求中性；黑话条目注明其功能与陷阱（详见第 27 章）。

## 一、生理与营养

| 术语 | 英文 | 释义 |
|---|---|---|
| 能量平衡 | energy balance | 摄入与消耗之差。长期为负则减重，为正则增重。本书的"正法"基石 |
| 静息代谢率 | RMR / resting metabolic rate | 静息状态下的能量消耗。减重后会下降，幅度常超出体重变化的预期 |
| 代谢适应 | metabolic adaptation / adaptive thermogenesis | 减重后总消耗下降超出预测的部分。平台期与反弹的核心机制之一 |
| 非运动性活动产热 | NEAT | 日常非刻意活动的消耗（走动、家务、小动作）。节食时会无意识下降 |
| 食物热效应 | TEF | 消化吸收食物本身的消耗。蛋白质最高 |
| 瘦素 | leptin | 脂肪组织分泌的饱腹信号激素。减重后下降，食欲反扑 |
| 胃饥饿素 | ghrelin | 胃分泌的饥饿信号激素。减重后上升 |
| 设定点 | set point | 假说：身体会 defended 一个体重区间。争议中，见第 22 章 |
| 沉降点 | settling point | 替代假说：体重由环境与行为被动"沉降"决定，无主动防御 |
| 体脂率 | body fat percentage | 脂肪占体重比例。家用 BIA 秤误差大，见第 20 章 |
| 生物电阻抗 | BIA | 家用体脂秤原理。受水合状态影响极大 |
| 双能 X 射线吸收 | DEXA | 体成分测量参考方法之一。仍有误差，非绝对真值 |
| 去脂体重 | LBM / lean body mass | 体重减去脂肪。含肌肉、骨骼、器官、水 |
| 渐进超负荷 | progressive overload | 逐步增加训练刺激。力量训练的核心原则 |
| 肌肉蛋白合成 | MPS | 肌肉修复与增长的生理过程 |
| 胰岛素敏感性 | insulin sensitivity | 细胞对胰岛素的响应程度。睡眠与运动显著影响 |
| 皮质醇 | cortisol | 应激激素。慢性升高与向心性脂肪相关（避免夸大因果） |

## 二、药物与临床

| 术语 | 英文 | 释义 |
|---|---|---|
| GLP-1 受体激动剂 | GLP-1 receptor agonist | 一类肠促胰素药物。作用于食欲与胃排空。本书只做机制科普，不给剂量 |
| 司美格鲁肽 | semaglutide | GLP-1 类药物之一。商品名与适应症以药监局公告为准 |
| 替尔泊肽 | tirzepatide | GIP/GLP-1 双受体激动剂 |
| 肥胖症 | obesity | 已被承认为一种慢性疾病。诊断以临床指南为准，非单看 BMI |
| BMI | body mass index | 体重(kg)/身高(m)²。人群筛查工具，个体判断力有限 |
| 减重门诊 | weight management clinic | 内分泌科/临床营养科/减重外科开设的专科门诊 |
| 注册营养师 | RD / registered dietitian | 有规范准入与继续教育的营养专业资格 |
| 公共营养师 | — | 曾列入职业资格，后调整为技能等级认定。见第 15 章 |
| 运动处方 | exercise prescription | 个体化的运动干预方案。中国落地受体制与支付限制，见第 16 章 |
| 进食障碍 | eating disorder | 一类精神疾病。本书只写识别信号与求助路径 |
| 身体变形恐惧 | body dysmorphic disorder | 对外貌缺陷的过度先占观念。与健身人群高度相关 |
| 循证实践 | EBP / evidence-based practice | 结合最佳证据、专业判断与个体情况的实践方式 |

## 三、行业与认证

| 术语 | 英文 | 释义 |
|---|---|---|
| 国职 | — | 健身教练国家职业资格。政策历经变迁，见第 07 章 |
| NSCA-CSCS | Certified Strength and Conditioning Specialist | 美国国家体能协会认证，门槛较高 |
| ACE / ACSM / NASM | — | 美国运动委员会 / 美国运动医学会 / 美国国家运动医学会。各有认证体系 |
| CEC / CEU | continuing education credits | 继续教育学分。维持认证有效性的要求 |
| 年卡模式 | annual membership | 预付费会员制。收入依赖出席率低于盈亏平衡点，见第 02 章 |
| 月付制 | monthly membership | 按月付费。降低跑路风险，提高单价 |
| 预售 | pre-sale | 开业前售卡。现金流被挪用于扩张是暴雷主因之一 |
| 体验课转化 | trial conversion | 免费/低价体验课转为付费私教课的销售环节 |
| 封闭训练营 | closed weight-loss camp | 全封闭集中减重机构。青少年营的伦理问题见第 09 章 |
| 陪伴式减脂 | coached accountability | 线上打卡、饮食点评、周复盘。卖的是关系而非知识，见第 10 章 |
| 代餐 | meal replacement | 替代正餐的加工食品。有效性依赖能量差，不依赖产品本身 |

## 四、圈子黑话

> 黑话是入场券，也是思维捷径。学会一个圈子的话，就会开始替它辩护。

| 黑话 | 字面 | 实际功能 | 陷阱 |
|---|---|---|---|
| 干就完了 | 别想太多，练 | 终止讨论、强化行动认同 | 用口号替代推理，掩盖方法错误 |
| 三分练七分吃 | 饮食更重要 | 强调饮食权重 | 比例无科学依据，是修辞不是数据 |
| 科技与狠活 | 药物/补剂 | 划界：自然 vs 用药 | 道德化用药，掩盖真实风险讨论 |
| 自然 | 不用药物 | 身份标记与优越感 | "自然"无统一定义，补剂边界模糊 |
| 脏增肌 | 不控制饮食增重 | 为放纵提供正当性 | 脂肪增长被肌肉叙事掩盖 |
| 碳水后置 | 把碳水集中在某时段 | 制造方法优越感 | 时序效应远小于总量效应 |
| 易胖体质 | 天生容易胖 | 为失败提供外部归因 | 多为营销发明；真实差异存在但被夸大 |
| 代谢修复 | 恢复受损代谢 | 为平台期提供希望产品 | "代谢受损"是被曲解的概念 |
| 平台期突破 | 打破停滞 | 卖新课/新产品的钩子 | 平台期多是正常生理适应 |
| 局部减脂 | 瘦特定部位 | 卖器械/课程 | 脂肪动员是全身性的，无法定点 |
| 空腹有氧 | 空腹做有氧 | 制造方法优越感 | 总量差异下减脂效果无显著优势 |
| 排毒 | 排出毒素 | 卖产品 | 无生理学定义的营销词 |

## 五、本书专用词

| 词 | 释义 |
|---|---|
| 末法 | 借喻。信息洪水下真法淹没、劣币驱逐良币的状态。非宗教主张 |
| 正法 | 借喻。朴素、无聊、有效、无人问津的基础实践 |
| 像法 | 借喻。形式繁盛而实质流失：认证、话术、包装取代效果 |
| 三重故障 | 知识过剩 + 信任崩塌 + 激励错位。本书核心论点 |
| 双重解构 | GLP-1 解构"努力"，AI 解构"知识" |
| 不可外包的三样 | 身体所有权与感受力、长期关系的责任、共同体与意义 |
| 最小可行实践 | 少到不可能失败、久到不可能无效的最小系统。见第 37 章 |
| 证据卡 | evidence/claims/ 下的论断溯源单元。本书的可审计性机制 |
