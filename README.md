# 末法时代的胖子

> **《末法时代的胖子》** —— 当药物接管食欲、AI 接管知识，我们为什么还要练？
>
> 一本关于中国减肥行业的开源深度非虚构：知识过剩、信任崩塌、激励错位，以及一个胖子如何重新拿回自己的身体。

> **反弹不是 bug，是商业模式。**
>
> <sub>这句话指的是**激励结构**，不是生理成因。反弹的成因是四件事叠加，而其中唯一被随机对照试验证明能改的那一件——持续的外部支持——恰好是行业最不赚钱、因而不提供的那一件。**行业不制造反弹，它制造的是「反弹之后没有人管」。**</sub>

## 一句话主旨

中国减肥的困境，从来不是"胖子不够自律"，而是一个**知识过剩、信任崩塌、激励错位**的三重系统故障。出路不是更多方法，而是**更少的方法 + 更真的关系 + 更长的时间**。

## 三重故障

| 故障 | 内容 | 后果 |
|---|---|---|
| **知识过剩** | 有效知识极简且免费（能量差、蛋白质、力量训练、睡眠、时间），却被埋在指数级增长的噪音里 | 信息的边际收益为负，"研究"代替了"开始" |
| **信任崩塌** | 能给你建议的人，几乎都靠你的失败赚钱 | 无法分辨谁在说真话，只能信情绪与人格 |
| **激励错位** | 行业收入 = f(焦虑 × 复发率)，而不是 f(健康结果) | 年卡对赌你不来，代餐靠你复购，训练营靠你复发 |

**没有任何一个主流商业模式的 KPI 是"你三年后还健康且不反弹"。**

2024–2026 年，两件事同时发生：**GLP-1 针剂解构了"努力"**（原来食欲是激素，不是道德），**AI 解构了"知识"**（定制方案的边际成本趋零，伪科普的生产成本也趋零）。旧行业的两条护城河被同时抽干。于是全书真正要回答的问题浮现出来：

**当知识免费、努力可选，人为什么还要练？**

## 目标读者

- 反复减肥、反复反弹，已经被方法淹没的普通人
- 健身教练、前教练、工作室主理人——想知道自己为什么越干越心虚
- 营养师、医生、体育院校学生——想看清楚专业教育与市场之间的断层
- 行业研究者、投资人、政策观察者——需要一份带证据链的全景解剖
- 资深爱好者与社区维护者——想搞清楚圈子为什么永远在撕

**不写给谁**：想要"7 天瘦 10 斤食谱"的人。本书不提供方案，提供**判断方案的框架**。

## 立场

胖子不是失败者，是被系统性误导、被焦虑征税、被激励错位收割的人。

本书**反身材羞辱、反意志力叙事**。不使用羞辱性前后对比图，不把体重挂在道德上。书名里的"胖子"是自称，不是他称；"迷失"（lost）指的是被噪音淹没，而不是"失败"（loser）。

## 这本书怎么做到"可审计"

末法不是道德堕落，是信息经济学的必然均衡：**复制信息的成本趋零，而验证信息的成本不变时，劣币驱逐良币是默认态。** 所以骂骗子没用，要改的是验证机制。

这本书用开源方式写作，就是在示范验证机制长什么样：

- **[evidence/claims/](evidence/claims/)** —— 每条关键论断一张卡：说法、证据、分级、反方意见、最后核查日期。正文里的数字和断言可以顺着卡片查到底
- **[evidence/claims/INDEX.md](evidence/claims/INDEX.md)** —— **口径裁决表**：同一事实出现多个数字时，以这里为准。附独立性警告、原文异常登记、黑名单来源
- **[evidence/data/](evidence/data/)** + **[evidence/scripts/](evidence/scripts/)** —— 原始数据与可复现脚本，采集日期与来源随数据一起版本化
- **[SOURCES.md](SOURCES.md)** —— 全部素材来源与融入计划，公开可查
- **[CONFLICTS.md](CONFLICTS.md)** —— 作者利益冲突声明：我靠这本书得到什么，先说清楚
- **[CHANGELOG.md](CHANGELOG.md)** + 公开修订历史 —— 作者保留随时推翻自己的权利，推翻过程也公开

### 已经发生的推翻（这是功能，不是事故）

**57 张证据卡建好之后，本书自己的七处大纲假设被推翻了。** 它们没有被悄悄改掉，而是列在 [meta/OUTLINE.md §0.9](meta/OUTLINE.md)：

| 章 | 原来打算写的 | 证据说的 |
|---|---|---|
| 22 | 代谢适应是反弹主因 | 普通干预下仅 30–100 kcal/d，1–2 年消失，不预测反弹 |
| 22 | 超级减肥王代谢暴跌 789 kcal/d | 该数字 2016 年已被更正为 664，且结论反转 |
| 05 | 女性身材焦虑持续升级 | 跨时代 meta 显示瘦导向分数在**下降**；中国数据方向相反 |
| 34 | 针剂毁肌肉，所以必须练 | **药组与安慰剂组同为 75/25**——那是减重的组成，不是药的毒性 |
| 35 | AI 用同样的确定性说对的和错的 | 校准已改善（ECE 0.06–0.127），但**科室间差三倍** |
| 35 | 动作视觉纠错还在演示阶段 | 已有 16 周临床验证 |
| 36 | 不可外包的三样东西 | **一样有 RCT，两样是立场**——已分级标注 |

**如果一本书的论点是「信任崩塌」，而它自己的大纲被证据推翻时却悄悄改掉，那它就在做它批判的事。**

## 姊妹书

**《末法时代的程序员》**（`standup-coder/the-lost-coder`，规划中）——同一套「末法」透镜，另一个行业。

那本书问：当写代码不再稀缺，程序员这个身份还剩下什么？
这本书问：当药物接管食欲、AI 接管知识，我们为什么还要练？

两本共享同一个辩证转折：**入门从未如此容易，成道从未如此艰难。** 一本写劳动的去技能化，一本写身体的去道德化。
